# Başlık ve altyazı efektleri

Videonun üstüne gelen şeffaf animasyonlar. Her HTML dosyası `setT(saniye)` fonksiyonuyla çalışır; `render_ornek.js` kareleri PNG olarak alır, ffmpeg videonun üstüne bindirir.
Yazı ve renkler HTML içinde değişir. Fontlar `../fonts/` klasöründeki `local.css` ve `local2.css` ile yüklenir (HTML'i `video-sablonlari` içine koyup çalıştır).
